# Quran Recite — мини-апп для проверки начитки в Telegram

Что уже сделано в этом скелете:
- авторизация через Telegram Mini App (проверка подписи на сервере);
- база данных Supabase с изоляцией по пользователю (RLS);
- запись голоса в браузере одной кнопкой;
- распознавание речи (Groq Whisper) → сверка с эталонным текстом аята
  пословно (без огласовок, устойчиво к мелким расхождениям ASR) →
  подсветка каждого слова: зелёное — верно, оранжевое — расхождение,
  серое — пропущено;
- сохранение попыток и прогресса по каждому аяту в базу.

Чего здесь **нет** и что придётся достраивать самим по мере роста:
- полной базы аятов Корана (сейчас в коде один демо-аят для примера);
- экрана выбора суры/аята, списка прогресса, платной подписки;
- обработки качества звука (шум, слишком тихая запись);
- более мягкой сверки, учитывающей таджвид, а не только правильность слов.

## Что нужно сделать именно вам — по шагам

### 1. Создать бота в Telegram
1. Написать `@BotFather` в Telegram → `/newbot` → задать имя и username бота.
2. Скопировать выданный токен — это `TELEGRAM_BOT_TOKEN`.
3. В том же BotFather: `/newapp` (или в меню бота "Bot Settings → Menu Button")
   → указать URL, по которому будет открываться мини-апп (получите его после
   деплоя на шаге 5, пока можно поставить заглушку).

### 2. Создать проект Supabase
1. Зарегистрироваться на supabase.com, создать новый проект (выбрать регион
   ближе к вашей аудитории).
2. Project Settings → API → скопировать `Project URL` и `anon public key`
   → это `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
3. Там же скопировать `service_role` ключ (секретный!) → `SUPABASE_SERVICE_ROLE_KEY`.
4. Открыть SQL Editor в Supabase → вставить содержимое файла
   `supabase/schema.sql` из этого проекта → Run.

### 3. Получить ключ для распознавания речи
1. Зарегистрироваться на console.groq.com.
2. API Keys → создать ключ → это `GROQ_API_KEY`. У Groq есть бесплатный лимит,
   его достаточно, чтобы протестировать продукт на первых пользователях.

### 4. Собрать локально и проверить
1. Скопировать `.env.example` в `.env.local`, вставить все ключи из шагов 1–3.
2. `npm install`
3. `npm run dev` — приложение поднимется на localhost:3000.
   Учтите: Telegram-авторизация не заработает в обычном браузере — она
   проверяется только когда страница открыта изнутри Telegram (см. пункт 6).

### 5. Задеплоить
1. Загрузить код в GitHub-репозиторий.
2. На vercel.com → New Project → импортировать репозиторий.
3. В Vercel → Settings → Environment Variables добавить все переменные
   из `.env.local`.
4. Deploy. Скопировать выданный домен (например `your-app.vercel.app`).

### 6. Привязать домен к боту
1. Вернуться в `@BotFather` → выбрать бота → Bot Settings → Menu Button
   → вставить `https://your-app.vercel.app`.
2. Открыть бота в Telegram, нажать кнопку меню — мини-апп должен открыться
   и сразу авторизовать вас без пароля.

### 7. Наполнить базу аятами
Демо-версия работает с одним аятом, зашитым в код (`src/app/page.tsx`).
Чтобы это стало реальным продуктом:
1. Взять открытый датасет текста Корана с построчной разбивкой по аятам
   (например данные с tanzil.net — там есть версия с огласовками и без).
2. Залить его в таблицу `ayahs` через Supabase Table Editor или скриптом.
3. Добавить экран выбора суры/аята вместо захардкоженного `DEMO_AYAH`.

### 8. Протестировать на живых людях как можно раньше
Дайте прочитать 2–3 знакомым, которые реально читают Коран, ещё до того,
как продукт «готов». Алгоритм сверки в `src/lib/compare-recitation.ts` —
первая грубая версия, ей нужна калибровка на реальных ошибках распознавания,
а не только на ваших собственных тестах.

## Структура проекта

```
src/
  app/
    page.tsx                     — главный экран
    layout.tsx                   — подключение Telegram SDK
    api/auth/telegram/route.ts   — проверка подписи Telegram, создание пользователя
    api/recite/check/route.ts    — приём аудио → распознавание → сверка → сохранение
  components/
    RecitationRecorder.tsx       — кнопка записи
    AyahDisplay.tsx               — подсветка результата сверки
  lib/
    telegram-auth.ts             — верификация initData
    supabase.ts                   — серверный клиент Supabase
    compare-recitation.ts        — алгоритм пословной сверки
supabase/
  schema.sql                     — таблицы + политики доступа
```
